# Contributing

Thanks for wanting to improve the WhiteFish Usage Dashboard. Issues and pull requests are welcome.

By submitting a contribution (a pull request, patch, issue attachment or anything else), you agree that WhiteFish Creative Limited may use, modify, relicense and distribute it as part of this project or otherwise, and you confirm you have the right to grant that.

Before opening a pull request, run:

```bash
claude plugin validate .
claude plugin test .
```
